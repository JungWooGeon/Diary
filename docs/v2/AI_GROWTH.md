# v2 개정 4: AI 총동원 + 유입·유지·수익 (2026-11-22)

> 사용자 결정 (11/22)
> - 2.6GB 대화형 AI(Gemma)는 뺀다. 사용자가 받을 리 없다.
> - 대신 "AI로 할 수 있는 모든 기능"을 비용 0원, 큰 다운로드 없이 넣는다.
> - 정체성(무드등 온이, 기분이 빛이 되는 일기장)을 지키고, 유입·유지·수익에 집중한다.
> - 웹에서 0원으로 AI 답장이 가능하면 웹에만 두고, 앱에서는 "웹에서 받을 수 있어요"로 안내한다.

## 1. 원칙

- **AI 기능은 전부 무료**예요. 감정을 잠그면 1~2점 리뷰가 달린다(PLAN §2). AI는 리뷰와 입소문의 재료예요.
- **AI 결과는 늘 "제안"**이에요. 감정·태그는 사용자가 눌러야 적용된다.
- **용량**
  - 앱에 더하는 모델은 수십 MB 이하예요.
  - Google Play 서비스가 처리하는 ML Kit(unbundled)을 먼저 쓴다.
  - 따로 받는 모델(손글씨)은 켤 때 크기를 보여 주고 받는다.
- **"AI" 표기는 실제 모델이 한 일에만** 붙여요. 준비된 문장은 "온이의 한마디"로 부르고, AI라고 하지 않는다.
- 위기 감지는 모든 AI 기능보다 먼저 돈다. 기존 규칙을 그대로 쓴다.

## 2. AI 기능 목록

### 2.1 감정 AI (앱 내장 분류기 + 문장 임베딩, 추가 용량 ≈ 0)

| # | 기능 | 화면 | 내용 |
|---|---|---|---|
| E1 | **쓰는 동안 빛이 변해요** | 쓰기 | 입력을 멈추면(약 1초) 본문을 분류해 온이 미리보기 빛이 은은하게 그 색으로 바뀌어요. 확정은 사용자가 해요. 정체성의 핵심 연출이에요 |
| E2 | 감정 추천 (기존) | 쓰기 | 저장 전에 감정 칩을 제안해요 |
| E3 | **문장별 감정 하이라이트** | 일기 보기 | 감정이 진한 문장 밑에 그 감정의 빛 색으로 밑줄을 쳐요. 켜고 끌 수 있어요 |
| E4 | **비슷했던 날** | 저장 후 · 일기 보기 | 결이 비슷한 과거 일기 1~3개를 보여 줘요: "그때는 이렇게 지나갔어" |
| E5 | **뜻으로 검색** | 검색 | 단어가 달라도 비슷한 내용을 찾아요(임베딩 + 기존 글자 검색 섞기) |
| E6 | **자동 제목** | 쓰기 | 제목이 비면 대표 문장이나 핵심 단어로 제목을 제안해요 |
| E7 | **이번 달의 한 줄** | 월간 리포트 | 한 달을 대표하는 문장을 골라요(임베딩 중심성) |
| E8 | **감정 원인 찾기** | 리포트 | 감정 × 태그·활동·사람·날씨·요일·시간대를 분석해요. 예: "친구 만난 날 설렘 +40%", "비 오는 날 저녁 외로움" |
| E9 | **마음 예보** | 오늘 · 알림 | 패턴으로 미리 챙겨요: "금요일 밤엔 지치는 편이에요. 오늘은 일찍 쉬어 볼까?" (주 1회 이하) |
| E10 | **주간 온이 편지** | 일요일 밤 알림 · 리포트 | 이번 주 빛, 자주 느낀 감정, 이번 주의 한 줄, 원인 한 가지를 담아요. 공유 카드도 돼요 |
| E11 | **마음 체크인** | 오늘 | 가라앉는 감정이 며칠 이어지면 부드럽게 안부를 물어요. 위기 표현이 있으면 도움 안내를 우선해요 |
| E12 | **스마트 리마인더** | 알림 | 주로 쓰는 시간을 배워 그 시간에 불러요(직접 정한 시간이 우선) |
| E13 | **키워드 구름** | 월간 리포트 | 이번 달에 자주 나온 사람·장소·활동이에요 |

### 2.2 사진·글자 AI (ML Kit, Play 서비스)

| # | 기능 | 내용 |
|---|---|---|
| V1 | 사진 자동 태그 | 바다, 고양이, 음식… → 태그를 제안해요 |
| V2 | **사진 색 → 빛** | 사진의 주된 색으로 오늘 빛을 제안해요(색 추출) |
| V3 | 종이 일기 옮기기 | 문서 스캐너 + 한국어 글자 인식(OCR)으로 종이 일기를 옮겨요 |
| V4 | 사진 스티커 | 사진에서 사람이나 물건만 오려 일기에 붙여요 |
| V5 | 손글씨로 쓰기 | 태블릿과 펜으로 써요. 한국어 잉크 모델은 켤 때 받아요 |

### 2.3 웹

| # | 기능 | 내용 |
|---|---|---|
| W1 | 감정 AI | 같은 분류기(약 15MB)를 브라우저에서 돌려요(LiteRT/TFLite web). 처음 한 번만 받고 캐시해요. E1~E8을 웹에도 넣어요 |
| W2 | **온이 AI 답장(웹 전용)** | 크롬 내장 AI(Gemini Nano, Prompt API)가 **이미 받아져 있는 브라우저에서만** 써요. 다운로드를 유도하지 않아요. 안 되면 "온이의 한마디"로 대신해요. 약관과 연령 조건은 확인 후 적용해요 |
| W3 | 앱 안내 | 앱의 답장 카드에 "웹(PC 크롬)에서는 온이가 직접 답장을 써 줘요"라고 안내해요. W2가 실제로 가능할 때만 보여 줘요 |

## 3. 유입 (사용자를 데려오는 것)

- **공유 카드가 광고판이에요.** 오늘의 빛, 주간 온이 편지, 월간 빛 캘린더, 올해의 빛을 인스타 스토리 비율로 만들어요. 카드 아래에 작게 "온이 일기"와 웹 주소를 넣어요. 프리미엄은 워터마크 없이 만들 수 있어요.
- 스토어(ASO): 제목 "온이 - AI 일기장, 감정일기 다이어리". 설명에 AI 기능을 구체적으로 써요. 감정일기, 무드트래커, 감정 캘린더, 일기장 위젯, 종이 일기 옮기기.
- 웹이 검색 유입 창구예요. 랜딩에 기능 소개와 Play 링크를 둬요. 웹에서 바로 써 볼 수 있어요.
- v1 기존 사용자는 업데이트로 자동 이전돼요. 그대로 유지예요.

## 5. 수익

- 무료 + 광고 조금 + **프리미엄 평생 3,300원 하나**(구독 없음, 상품 쪼개기 없음).
- 광고 위치는 기존 그대로예요: 캘린더·리포트 배너, 타임라인 네이티브 1개, 보상형(특별 팔레트 하루 체험). 작성·저장·답장·잠금 화면과 전면 광고는 계속 금지예요.
- 프리미엄
  - 광고 영구 제거
  - 올해의 빛
  - 특별 팔레트와 글꼴
  - PDF 일기책
  - 공유 카드 워터마크 끄기 + 카드 테마
- 결제를 권하는 순간(부드럽게, 하루 1회 이하)
  1. 7일 연속 기록
  2. 보상형으로 체험한 팔레트가 끝날 때
  3. 공유 카드를 만들 때
  4. 연말 올해의 빛
- AI 기능은 프리미엄으로 잠그지 않아요(§1).

## 6. 진행 순서

1. LLM 제거(진행 중) · 분류기 임베딩(진행 중) · ML Kit(진행 중)

3. 개인정보처리방침·이용약관 점검과 수정(앱·웹·store 문서)
4. 통합 QA: 노트20 + 에뮬레이터 + 웹
5. 스크린샷 재촬영, 스토어 설명 수정, Play Console 전체 수정(데이터 보안, 콘텐츠 등급, 앱 콘텐츠), AAB 202 업로드, 검토 제출
