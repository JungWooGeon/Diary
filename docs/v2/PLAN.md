## 1. 한 줄 정의

**"기분을 톡 누르면 온이가 그 색으로 켜지고, 하루를 들어 주는 감정 일기장"**

- 1초 만에 기분을 남기고, 쓰고 싶은 날엔 길게 쓴다.
- 온이가 답장해 주고, 원하면 대화도 한다.
- 쌓인 빛으로 내 마음의 흐름을 보여 준다.

## 3. 기능 명세

### 3.1 기록

| 기능 | 내용 | 무료 |
|---|---|---|
| **1탭 기분** | 홈이나 위젯에서 대표 기분 5개 중 하나를 탭하면 바로 저장되고, 온이가 그 색으로 켜짐 | ✅ |
| **감정 다중 선택 + 강도** | 감정 20종(아래) 중 여러 개를 고르고 각각 강도 1~5를 정하면, 온이 빛이 섞인 색이 됨 | ✅ |
| **하루 여러 번** | 아침·점심·밤 기록이 따로 남고, "하루의 빛" 타임라인으로 이어짐 | ✅ |
| 본문 | 입력을 멈추고 1초 뒤 자동 저장. 쓰다 나가도 초안 유지. 글자 수 제한 없음 | ✅ |
| 템플릿 | 자유 / 세 줄 / 감사 3가지 / 오늘의 질문 | ✅ |
| 사진 | 일기당 최대 5장, 압축 저장 | ✅ |
| 말로 쓰기 | 기기 음성 인식으로 받아쓰기 (원문 그대로) | ✅ |
| 태그 | 사람·장소·활동 태그. 본문에서 **자동 제안** (§3.2) | ✅ |
| 날씨 | 선택하면 그날 날씨를 자동 기록 (Open-Meteo, 키·비용 없음) | ✅ |
| 지난 날짜 쓰기 | 놓친 날도 날짜를 골라 작성 | ✅ |

**감정 20종** (5그룹 × 4개, 그룹 = 빛 색 계열)
- 밝음(노랑): 기쁨, 뿌듯함, 신남, 감사
- 평온(초록): 편안함, 차분함, 안심, 홀가분
- 설렘(분홍): 설렘, 사랑, 기대, 그리움
- 가라앉음(파랑): 슬픔, 우울, 외로움, 서운함
- 지침(보라): 피곤, 불안, 짜증, 화남
- 그 외: **잘 모르겠음**. 빛이 켜지지 않고, 온이가 "괜찮아, 그런 날도 있어"라고 말함

하루 빛 색은 강도와 섞기 규칙(설계서 §4.2)으로 정해진다. 감정 이름과 색은 무료로 수정할 수 있다.

### 3.2 온이 (AI)

AI는 앱에 포함되어 모든 폰에서 바로 돈다. 서버를 쓰지 않으므로 일기가 폰 밖으로 나가지 않는다.
- 대화형 AI(Gemma 4 E2B/E4B, 약 2.6GB 선택 다운로드 "온이 깨우기")는 만들었다가 2026-11-22에 뺐다. 수 GB 다운로드는 하지 않는다.

| 기능 | 동작 (모든 폰) |
|---|---|
| **감정 자동 추천** | 본문을 읽고 감정과 강도를 추천 (소형 감정 분류기) |
| **태그 자동 제안** | 사람·장소·활동 추출 (형태소 분석 + 사전) |
| **위기 안전장치** | 자해·자살 표현을 감지하면 답장 대신 109·1577-0199 안내 (규칙 + 분류기, 놓치지 않는 쪽으로 설정). 답장보다 항상 먼저 동작 |
| **온이 답장** | 감정 × 강도 × 태그별로 **직접 쓴 답장 문구 수백 개** 중에서 골라, 일기 속 단어를 넣어 완성 |
| **자동 제목** | 첫 문장과 핵심 단어로 만듦 |
| **말로 쓰기** | 받아쓴 원문 그대로 |
| **대화로 쓰기** | 온이가 준비된 질문으로 3~5번 묻고, 답을 이어 붙여 일기 한 편으로 만듦 |
| **오늘의 질문** | 최근 감정·태그를 넣은 질문 문구 |
| **주간·월간 회고** | 통계 + 문장 템플릿 ("이번 주엔 ○○와 함께한 날 빛이 밝았어") |

- **답장 표시**: 답장은 준비된 문장이라 "온이의 한마디"로 표시한다(AI 생성물 아님). 부적절한 답장 신고 버튼은 그대로 둔다.
- **AI 끄기**: 설정에서 언제든 끌 수 있다. 끄면 순수 일기장으로 동작한다.
- 의료·상담 서비스가 아니라는 점을 온보딩과 설정에 고지한다.

### 3.3 온이와 지내기

- **홈의 온이**: 오늘 기록한 빛 색으로 켜져 있다. 기록이 없는 날은 꺼진 채 졸고 있다. 탭하면 표정이 바뀌고 한마디 한다.
- **온이 편지함**: 지금까지 받은 답장을 모아 본다.
- **빛 수집**: 연속 기록·누적 기록에 따라 새 빛 팔레트와 소품(갓 무늬, 받침, 계절 장식)을 얻는다. 기본 수집은 무료이고, 일부 특별 팔레트는 프리미엄이다.
- **리마인더**: 원하는 시간에 온이가 매번 다른 말로 부른다 ("불 켜 둘게, 오늘 얘기 들려줘").
- **타임캡슐**(v2.1): 미래의 나에게 편지를 쓰면, 그날 온이가 전해 준다.

### 3.4 보기

| 기능 | 내용 |
|---|---|
| **무드 캘린더** | 날짜 칸이 그날 빛 색으로 물든다. 여러 번 기록한 날은 그라데이션 |
| **하루의 빛** | 하루 동안 기록한 감정을 시간축 빛 띠로 보여 준다 (어느 앱에도 없음) |
| 타임라인 | 사진·답장과 함께 스크롤 |
| **검색** | 단어·감정·태그·기간으로 검색 |
| 1년 전 오늘 | 홈 카드 + 알림(선택) |
| 사진 모아 보기 | 월별 사진 격자 |

### 3.5 리포트 (기본 무료)

- **주간**(매주 월요일): 빛 분포, 가장 밝았던 날, 자주 함께한 사람·활동, 온이 한마디
- **월간**: 감정 TOP 3, 요일·시간대 패턴, **감정 × 활동/사람 관계**("산책한 날 평온 +40%"), 연속 기록
- **연간 "올해의 빛"**: 365칸 빛 모자이크, 공유 카드(인스타 스토리 비율). 이것만 프리미엄
- 모든 통계는 기기에서 계산한다 (서버 없음)

### 3.6 백업·동기화·이전

- **자동 백업 위치는 내 Google 드라이브의 앱 전용 폴더다.** 다른 앱이나 사람에게는 보이지 않고, 우리 서버도 거치지 않는다. 저장할 때마다 변경분을 올리고, **올린 뒤 다시 읽어서 확인**한다.
- **새 폰**: 같은 Google 계정으로 로그인하면 일기가 자동 복원되고, 프리미엄 결제도 자동 복원된다.
- **v1 사용자**: 업데이트만 하면 기존 일기와 이모티콘이 자동으로 옮겨진다.
- **내보내기**: 텍스트는 무료, PDF 월간 일기책은 프리미엄이다.
- 계정과 데이터를 완전히 삭제할 수 있다 (드라이브 백업 포함).

### 3.7 잠금·꾸미기·위젯

- **잠금**(무료): PIN + 지문/얼굴, 재잠금 시간 선택, 최근 앱 화면 가리기, 위젯·알림에 내용 숨김
- **꾸미기**: 라이트/다크/종이 테마, 폰트 3종(서브셋으로 용량 최소화), 글자 크기. 기본은 무료, 추가 테마·폰트는 프리미엄
- **위젯**: ① 1탭 기분 입력 ② 오늘의 온이(빛 색) ③ 월간 빛 캘린더

## 4. 무료 / 프리미엄

| | 무료 | 프리미엄 평생 3,300원 |
|---|---|---|
| 기록 전부, 감정 20종, 강도, 여러 번 기록 | ✅ | ✅ |
| 온이 답장·감정 추천·대화로 쓰기 | ✅ | ✅ |
| 캘린더·검색·주간/월간 리포트 | ✅ | ✅ |
| 잠금·자동 백업·새 폰 복원 | ✅ | ✅ |
| 광고 | 조금 | **영구 제거** |
| 올해의 빛 (연간 리포트·공유 카드) | ❌ | ✅ |
| PDF 일기책 내보내기 | ❌ | ✅ |
| 특별 빛 팔레트·온이 소품·추가 테마·폰트 | 일부 | 전부 |

- **AI를 무료로 다 주는 이유**: 온디바이스라 우리 비용이 0원이다. 그리고 AI가 가장 큰 차별점이라 쓰는 문턱을 낮춘다.
- **가격 근거**: Play 일기 앱의 한 번 결제 가격은 1,000~3,300원이 주류다. 해마 일기 평생권 2,640원, 꼬박일기 평생권("커피값보다 싸다, 바로 결제"), 데이픽 평생 900원. 3,300원은 이 구간 안에 있다.

### 광고 (무료 사용자, "조금")

- **넣는 곳**: 캘린더·통계 화면 하단 배너 1개, 타임라인 중간 네이티브 광고 1개
- **보상형 광고(선택)**: "광고 보고 특별 빛 팔레트 하루 써 보기"
- **절대 안 넣는 곳**: 작성·저장·답장·잠금 해제 화면. 전면 광고는 쓰지 않는다
- 서버비가 0원이라 광고 수익은 거의 그대로 남는다
