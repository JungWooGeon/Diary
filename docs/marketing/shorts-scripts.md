# 숏폼 스크립트 5편 (릴스·쇼츠·틱톡, 15~20초)

## 공통 촬영 가이드

- **화면 녹화**: 디버그 빌드 + 샘플 데이터. 실제 사용자 일기는 절대 찍지 않아요.
  - 샘플 넣기: `adb shell am broadcast -n com.pass.diary/.DebugSeedReceiver` (이번 달 + 1월~지난달 1년치 빛)
  - 화면 열기: `adb shell am start -n com.pass.diary/.MainActivity --es nav <today|write:seed-draft|view:seed-today-3|calendar|report|year|letter:0>`
  - 녹화: `adb shell screenrecord --size 1080x1920 /sdcard/clip.mp4` (최대 3분)
  - 상태 표시줄은 SystemUI 데모 모드(스토어 스크린샷과 같게), 다크 모드
  - 광고는 디버그 프리미엄 플래그로 숨겨요. 단, 프리미엄 기능을 무료처럼 보이게 찍지 않아요(5편 참고).
  - 한국어 입력은 `adb input`으로 안 되니 실기기에서 직접 치거나 `DebugAiReceiver --es clip '…'`로 붙여 넣어요.
- **무드**: 감성 룩북 톤이에요.
  - 필름톤, 어두운 방에 화면 빛이 손과 책상에 번지는 장면
  - 쇼핑몰 누끼 컷, 형광펜 자막은 쓰지 않아요
  - 실사 B롤은 선택이에요: 밤 책상, 이불 속 폰 불빛, 창가 오후 빛 등 직접 찍을 수 있는 것만
- **자막**: 작고 가는 글씨, 화면 아래 1/3, 한 컷에 한 줄. 플랫폼 UI(오른쪽 버튼, 아래 캡션)를 피해 안쪽에 둬요.
- **음악**: 플랫폼 제공 음원 라이브러리만 써요. 저작권 음원 직접 넣기 금지.
- **표현**: "AI"는 실제 모델이 하는 기능(감정 읽기, 문장 밑줄, 비슷했던 날, 글자 인식)에만 붙여요. 온이의 한마디와 주간 편지는 AI라고 하지 않아요. 치료·효과 표현도 쓰지 않아요.
- **고정 해시태그**: #온이일기 #감정일기 #일기앱 (+ 편마다 3~5개)

## 1편. 쓰는 동안 빛이 변해요 (대표 영상)

길이: 18초 · 화면: `write:seed-draft`

| 초 | 장면 | 화면 자막 |
|---|---|---|
| 0–2 | 어두운 방, 꺼진 듯 은은한 온이(쓰기 화면 위쪽) 클로즈업 | 오늘 기분, 무슨 색이었어요? |
| 2–8 | 본문을 천천히 입력: "퇴근길에 좋아하는 노래가 나왔다. 괜히 마음이 말랑해졌어." | (자막 없음, 타이핑 소리만) |
| 8–12 | 입력을 멈추고 1초 뒤, 온이의 빛이 부드러운 색으로 번져요. 화면을 천천히 확대 | 쓰다 멈추면, 빛이 변해요 |
| 12–15 | 감정·제목 추천 칩이 뜨고, 손가락으로 감정 하나를 눌러요 | AI는 추천만, 고르는 건 나 |
| 15–18 | 저장 → 오늘 화면의 온이가 그 빛으로 켜진 모습 | 감정 AI는 폰 안에서만 돌아요 |

- **캡션**: 일기를 쓰다 잠깐 멈추면 무드등 온이가 글의 감정 색으로 켜져요. 감정 AI는 폰 안에서만 돌아서 글이 서버로 가지 않아요.
- **해시태그**: #온이일기 #감정일기 #일기앱 #무드등 #다이어리앱 #하루기록 #기록하는삶

## 2편. 1초 기분 기록

길이: 15초 · 화면: 홈 화면 위젯(`DebugSeedReceiver --es pin mood`로 위젯 고정) → `today` → `calendar`

| 초 | 장면 | 화면 자막 |
|---|---|---|
| 0–3 | 침대에 누워 폰을 드는 손(실사 B롤 또는 화면만) | 일기 쓸 힘도 없는 날 |
| 3–7 | 홈 화면 위젯에서 기분 하나를 톡 | 톡, 한 번이면 끝 |
| 7–11 | 앱을 열면 온이가 그 색으로 켜져 있어요 | 오늘의 빛이 켜졌어요 |
| 11–15 | 캘린더로 넘겨 한 달이 빛으로 물든 화면 | 모이면 한 달이 이렇게 |

- **캡션**: 길게 못 쓰는 날엔 위젯에서 기분만 톡. 한 달이 지나면 캘린더가 그날그날의 빛으로 물들어요.
- **해시태그**: #온이일기 #감정일기 #일기앱 #무드트래커 #위젯꾸미기 #홈화면꾸미기 #기분기록

## 3편. 그때는 이렇게 지나갔어

길이: 20초 · 화면: `view:seed-today-3`

| 초 | 장면 | 화면 자막 |
|---|---|---|
| 0–3 | 지친 하루의 일기를 여는 장면 | 오늘 좀 무거웠던 날 |
| 3–9 | 천천히 스크롤, 감정이 진한 문장에 빛 색 밑줄이 보여요 | 마음이 진했던 문장엔 빛 밑줄 |
| 9–15 | 아래 "비슷했던 날" 카드가 나타나고, 지난 일기 하나를 눌러요 | 결이 비슷했던 지난 날을 찾아 줘요 |
| 15–20 | 지난 일기 화면. 마지막 문장에 잠깐 멈춤 | 그때도, 이렇게 지나갔어 |

- **캡션**: 힘든 날 일기를 다시 열면, AI가 결이 비슷했던 지난 일기를 찾아 줘요. 그때 어떻게 지나왔는지 다시 볼 수 있어요.
- **해시태그**: #온이일기 #감정일기 #일기앱 #일기쓰기 #기록의힘 #다이어리
- 메모: 샘플 일기가 너무 어두운 내용이면 다른 샘플로 바꿔요. 위기 문장(`--ez crisis true`) 샘플은 절대 넣지 않아요.

## 4편. 종이 일기도 옮겨 와요

길이: 17초 · 화면: 쓰기 → 종이 일기 옮기기(문서 스캐너)

| 초 | 장면 | 화면 자막 |
|---|---|---|
| 0–4 | 책상 위 손글씨 노트(실사). 스탠드 불빛 | 몇 년 쓴 종이 일기장 |
| 4–9 | 폰으로 노트를 찍는 화면(스캐너) | 찍으면 |
| 9–14 | 인식된 한국어 글자가 확인 화면에 나오고, 한 글자를 손으로 고쳐요 | 글자로 옮기고, 확인해서 고쳐요 |
| 14–17 | 일기로 저장 → 온이가 켜짐 | 종이 일기도 빛이 돼요 |

- **캡션**: 노트에 쓴 일기를 찍으면 한국어 글자로 옮겨 줘요. 인식이 틀린 곳은 확인 화면에서 고친 뒤 넣어요.
- **해시태그**: #온이일기 #종이일기 #손글씨일기 #다이어리꾸미기 #일기앱 #아날로그감성
- 메모: 실사 노트는 직접 쓴 샘플 글만 찍어요. 인식이 한 번에 완벽한 척 편집하지 않아요. 고치는 장면을 그대로 둬요.

## 5편. 올해의 빛 (12월 1일~31일 게시)

길이: 20초 · 화면: `report` → "올해의 빛" 탭 → `year`

| 초 | 장면 | 화면 자막 |
|---|---|---|
| 0–3 | 실사: 창가에 서서히 지는 겨울 해, 또는 어두운 방의 폰 불빛 | 올해, 나는 무슨 색이었을까 |
| 3–8 | 리포트에서 "올해의 빛" 탭을 누르는 장면 | 365일의 기분을 |
| 8–14 | 365칸 모자이크가 화면을 채우는 장면. 천천히 위에서 아래로 훑기 | 한 장에 모았어요 |
| 14–18 | "올해 나는 ○○이었어요" 문장 + "기록한 날 N일 · 가장 밝았던 달 N월"에서 멈춤 | (자막 없음, 화면 글을 읽게 둬요) |
| 18–20 | 스토리 카드로 저장하는 장면 | 올해의 빛 · 온이 일기 |

- **캡션**: 1년 동안 남긴 기분이 하루 한 칸씩 빛이 돼요. 12월, 올해의 빛을 열어 보세요. (올해의 빛은 한 번 결제하는 프리미엄 기능이에요)
- **해시태그**: #온이일기 #올해의빛 #연말결산 #1년돌아보기 #연말회고 #감정일기 #2026결산
- 메모
  - 프리미엄 기능이라는 걸 캡션에 꼭 적어요. 무료처럼 보이게 하면 낮은 별점 리뷰가 달릴 수 있어요.
  - 화면의 숫자(기록한 날, 가장 밝았던 달)는 샘플 데이터 값이에요. 실제 통계처럼 자막에 옮기지 않아요.
  - 해시태그의 연도는 게시하는 해에 맞춰요.
